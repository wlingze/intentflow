参考：graphify 走的是另一条路

graphify 用 tree-sitter 把代码（以及文档 / PDF / 图片）抽成知识图谱：节点是概念，边标 EXTRACTED / INFERRED，输出 graph.html + graph.json，强调「查询图而不是 grep」。它做的是全仓库的静态地图，不是一次改动的三层 diff；代码层不调用 LLM。和上面的三个工具相比，它更接近「可遍历的项目知识库」，而不是「这次 PR 改了什么」。

同一 demo：examples/demo-go intentflow：./bin/intentflow diff --before … --after … PR Lens：pr-lens render examples/demo-go/pr-lens/graph.json Archify：archify compare architecture base.json head.json
